# 10xFamily Schedule Hub- MVP ideas

# Główny problem
Efektywne zarzadzanie, planowanie i przypominanie o wydarzeniach rodzinnych, głownie dotyczy dzieci - wizyty, zajęcia dodatkowe, lekarz, ortodonta, wycieczki, urodziny, itp, ale takżke rodziców. 
Główny problem dla rodziców: “Czy ogarniemy logistycznie ten dzień mając jedno auto i trójkę dzieci?”

# Najmniejszy zestaw funkcjonalności
## 1. Kalendarz wydarzeń
### Typy:
* jednorazowe,
* cykliczne.
### Event:
* tytuł,
* dziecko/osoba,
* data,
* godzina,
* lokalizacja,
* notatki,
* czy potrzebny samochód,
* kto jedzie.

CRUD:
* create/edit/delete/list.

## 2. Konflikty samochodu 🚗
Przykład:
* wtorek 17:00 → karate (auto potrzebne)
* wtorek 17:30 → dentysta (auto potrzebne)
App pokazuje:
> Konflikt — 2 wydarzenia wymagają samochodu.

## 3. Przypomnienia
Np:
* 1h wcześniej,
* dzień wcześniej.
Może być:
* email,
* push później,
* albo po prostu dashboard “dzisiaj”.

## 4. Dashboard “Dziś”
Homepage:
* dzisiejsze wydarzenia,
* kto potrzebuje auta,
* konflikty,
* najbliższe wydarzenia.

# Kryteria sukcesu
- prosta działająca appka, która pomoże w codziennych obowiązkach rodzicom
